# Study Duo

เว็บแอปสำหรับจัดการงานที่ต้องทำและวางแผนเวลาอ่านหนังสือไว้ในหน้าเดียว พัฒนาด้วย HTML, CSS และ JavaScript โดยไม่ต้องติดตั้งแพ็กเกจเพิ่มเติม

## ความสามารถ

- เพิ่มงานพร้อมชื่อวิชาและวันครบกำหนด
- ทำเครื่องหมายงานว่าเสร็จแล้ว หรือลบงาน
- เพิ่มตารางอ่านหนังสือพร้อมวิชา หัวข้อ วันที่ และเวลา
- ลบรายการอ่านหนังสือ
- บันทึกข้อมูลไว้ใน `localStorage` ของเบราว์เซอร์ เพื่อให้ข้อมูลยังอยู่เมื่อกลับมาเปิดหน้าเดิม
- รองรับหน้าจอขนาดเล็ก

## วิธีเปิดใช้งาน

1. ดาวน์โหลดหรือ clone โปรเจกต์นี้
2. เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์

ไม่ต้องติดตั้ง dependencies หรือเริ่มเซิร์ฟเวอร์เพิ่มเติม ทั้งนี้ Google Fonts จะโหลดเมื่อมีการเชื่อมต่ออินเทอร์เน็ต หากออฟไลน์ เว็บจะใช้ฟอนต์สำรองของระบบ

## โครงสร้างไฟล์

```text
Board work/
├── index.html   # โครงสร้างหน้าเว็บและฟอร์ม
├── style.css    # รูปแบบและการจัดวาง รวมถึง responsive layout
├── script.js    # การจัดการงาน ตารางอ่านหนังสือ และ localStorage
└── README.md    # คู่มือโปรเจกต์
```

## การจัดเก็บข้อมูล

ข้อมูลถูกเก็บไว้ในเบราว์เซอร์เครื่องและโปรไฟล์ที่ใช้เปิดเว็บ โดยใช้คีย์ต่อไปนี้:

- `studyBuddyTasks` สำหรับรายการงาน
- `studyBuddySessions` สำหรับตารางอ่านหนังสือ

ข้อมูลไม่ได้ซิงก์ข้ามอุปกรณ์หรือเบราว์เซอร์ การล้างข้อมูลเว็บไซต์ในเบราว์เซอร์อาจลบรายการที่บันทึกไว้
